# 真实二战兰博版：27 架二战飞机模型重制

`models/` 里是按历史资料重新生成的 27 架飞机的 VXL/HVA 文件，直接覆盖到游戏目录即可。`NAFAF`（雅克-9）是参考基准，没有改动。

## 安装

仓库里的 `真实二战兰博版.rar` 已经是更新后的完整版：27 架飞机的 VXL/HVA 已替换，`rulesmd.ini` 也已修改。

1. **先备份**你电脑上现有的“真实二战兰博版”文件夹（原版压缩包可以在仓库历史的第一个提交里找到）。
2. 解压新的 `真实二战兰博版.rar`，覆盖原文件夹。

只想替换模型的话，也可以只把 `models/` 里的 54 个文件复制进游戏目录。

## 对 rulesmd.ini 的修改

所有改动都由 `tools/rules/patch_rules.py` 从原版 `rulesmd.ini` 一次生成，只用尤里的复仇 + Ares 支持的标签：

```
python3 tools/rules/patch_rules.py 原版rulesmd.ini 新rulesmd.ini
```

### 1. 飞行姿态（重影、倾斜）
- `PitchSpeed` 过低会让飞机在几个俯仰角之间来回追赶，出现重影。以下单位统一改成 `1.1`：`A10W`、`KPLN`、`JAFSD`、`JAGDS`、`STFIGHTER`、`GERR`、`GERS`、`GERL`、`HORNET`、`J35`、`SU34`，以及下面全部战斗机。
- `RollAngle`：`B2BOMBER`、`STFIGHTER` 改成 `0`（之前停机时会歪）。`STFIGHTER` 的 `PitchAngle` 也改成 `0`。

### 2. 战斗机：二战式俯冲扫射
- 原来的武器用的是跟踪弹（`ROT=104`），加上 `ROF=5`、`Burst=10`、弹速 165，一口气打出大量高速子弹，战斗很快结束。
- 现在对地弹道改为 `ROT=0` 的直射曳光弹。在 YR 里，这会让飞机**直线冲过目标，沿途扫射，再绕回来**。`Ammo` 就是扫射的轮数。子弹带随机散布，一轮扫射会打出一串弹着点。
- 伤害：一轮扫射大约能打死几个步兵，打掉轻型车辆约 10～15% 的血；只有 37mm 炮和火箭弹能真正威胁重型坦克。
- 对空：单独的副武器，强跟踪曳光弹（`ROT=60`），射程 12，弹速 100。`OmniFire=yes` 保持不变，不然飞机在追击中对不准目标，就打不了敌机。

### 3. 航母
- `CARRIER`、`NIMITZ`、`NODCARRI`：`CanPassiveAquire=yes`，`GuardRange=26`（发射器射程 36 减 10），`Sight=12`。停在海上时，敌人进入 26 格内会自动起飞舰载机攻击。
- 发射器弹道改成 `Invisible3`（`AA=yes AG=yes`），航母可以锁定空中目标，自动派舰载机拦截。
- 黄蜂、蓝鲨、鸭嘴兽加了对空机枪副武器（`WW2_CarrierAirGun`），对地攻击保持不变。

### 4. 坦克主炮可以打偏
- 原来的坦克炮弹（`HeavyShellP_D1-7`、`TankShellP_D1-8`）是 `ROT=1`。在 YR 里 `ROT` 大于 0 就是跟踪弹，会一直追着目标，所以散布设置不起作用，总是命中。
- 现在改成低平的抛物线弹道（`Arcing=yes`、`ROT=0`，和火炮一样，火炮的散布是有效的），弹速从原来的约 110 提到 220，弹道很平，看起来仍然是直射曳光弹。散布 0.2～1.5 格（Ares `BallisticScatter`），会落空。
- 弹头（爆炸范围、边缘伤害）全部保持原版，没有改动。
- 车载机枪、火炮都没有改动。

## 修复了哪些“摇摇晃晃”的问题

| 问题（codex 版） | 现在 |
|---|---|
| hornet / j35 / su34 的体素间距是 0.607，不是 1.0。体素之间有缝隙，飞机转向时闪烁、镂空，螺旋桨也可能错位 | 所有部件的体素间距都是 1.0，和 NAFAF 一致 |
| 法线和几何形状对不上（平均吻合度 0.81～0.93），有 3～8% 的法线方向反了，转弯时光照忽明忽暗、看起来在抖 | 法线由几何形状平滑计算，吻合度 0.996，没有反向法线 |
| 翼面只有 1 个体素厚，旋转时会出现破洞、闪烁 | 翼面和尾翼至少 2 个体素厚 |
| 螺旋桨只有 2 帧，两帧之间转 45°～60°。游戏飞行时来回切换，大桨叶在两个位置间跳，看起来像重影、左右摇晃 | 螺旋桨改为 6 帧，每帧只转一小格（三叶桨 20°，四叶桨 15°），看起来是连续转动；轴心固定在桨毂上 |
| 机身边界没有居中，下方留了大量空白 | 边界在 x/y 方向居中，z 方向和 NAFAF 一样，大约 30% 在原点以下 |

## 比例

所有飞机按游戏平衡统一大小，不再按真实比例：

- **战斗机（单发）**：翼展统一约 85 体素，和 NAFAF 一样大。
- **双发飞机**：约 103 体素，比战斗机稍大。
- **四发重轰炸机**：约 116 体素。
- **舰载机**（hornet、j35、su34）：保持之前在游戏里的大小，55～88 体素。

模型太大会和旁边的飞机叠在一起，看起来就像重影。要调整的话，改 `tools/voxplane/builder.py` 里的 `SPAN_FIGHTER` / `SPAN_TWIN` / `SPAN_HEAVY`，或者 `aircraft.py` 里的 `CARRIER_S`，然后重新生成。

## 重新生成 / 修改

```
pip install numpy scipy pillow
cd tools/voxplane
python3 gen.py ../../models              # 生成全部
python3 gen.py ../../models hornet j35   # 只生成某几架
python3 check.py ../../models/hornet     # 检查法线、边界、螺旋桨帧
python3 render.py preview.png ../../models/hornet   # 生成预览图
```

- `aircraft.py`：每架飞机的尺寸、机翼、尾翼、发动机、座舱、炮塔、涂装和标志，单位是米。
- `builder.py`：体素化、法线计算、螺旋桨和 HVA 的生成。
- `paint.py`：迷彩、国籍标志、面板线和阵营色。

预览图在 `previews/`，每架飞机有俯视图和 RA2 视角图。
