# 真实二战兰博版：27 架二战飞机模型重制

`models/` 里是按历史资料重新生成的 27 架飞机的 VXL/HVA 文件，直接覆盖到游戏目录即可。`NAFAF`（雅克-9）是参考基准，没有改动。

## 安装

仓库里的 `真实二战兰博版.rar` 已经是更新后的完整版：27 架飞机的 VXL/HVA 已替换，`rulesmd.ini` 也已修改。

1. **先备份**你电脑上现有的“真实二战兰博版”文件夹（原版压缩包可以在仓库历史的第一个提交里找到）。
2. 解压新的 `真实二战兰博版.rar`，覆盖原文件夹。

只想替换模型的话，也可以只把 `models/` 里的 54 个文件复制进游戏目录。

## 对 rulesmd.ini 的修改

所有改动都由 `tools/rules/patch_rules.py` 从原版 `rulesmd.ini` / `artmd.ini` 一次生成，只用尤里的复仇 + Ares 支持的标签（没有 Phobos）：

```
python3 tools/rules/patch_rules.py 原版rulesmd.ini 新rulesmd.ini 原版artmd.ini 新artmd.ini
```

### 1. 飞行姿态（重影、倾斜）
- `PitchSpeed` 过低会让飞机在几个俯仰角之间来回追赶，出现重影。以下单位统一改成 `1.1`：`A10W`、`KPLN`、`JAFSD`、`JAGDS`、`STFIGHTER`、`GERR`、`GERS`、`GERL`、`HORNET`、`J35`、`SU34`，以及下面全部战斗机。
- `RollAngle`：`B2BOMBER`、`STFIGHTER` 改成 `0`（之前停机时会歪）。`STFIGHTER` 的 `PitchAngle` 也改成 `0`。

### 2. 战斗机：二战式俯冲扫射

YR / Ares 的相关机制（参考 Phobos 文档对原版行为的说明；真实二战里没有使用任何 Phobos 标签）：
- 武器弹道 `ROT` 小于 2 且不隐形时，飞机会**扫射**：直线冲过目标，沿途开 5 枪，再绕回来。一轮扫射只扣 1 发弹药，`Ammo` 就是扫射的轮数。原版里 `Burst`（连发）只对第一枪生效。
- 不带 `Inaccurate` 的弹药命中时会吸附到目标上，算直接命中。Ares 的 `BallisticScatter` 只对抛物线弹（`Arcing=yes`）有效。
- 原来能正常空战的战斗机都是一个武器同时对空对地（`AA=yes AG=yes`），新武器沿用这种写法。

新武器：
- 主武器（对地）弹道 `WW2_StrafeGunP`：`ROT=1`，和原版渡鸦一样；不带 `Inaccurate`，也不带 `Ranged`，子弹不会飞到一半消失。
- 副武器（对空）弹道 `WW2_AirHomingP`：照搬原来战斗机能打飞机的 `AircraftCannonP`（`ROT=104` 跟踪、接近即爆）。YR 打空中目标时会选用能对空的副武器。`ROT=1` 的扫射弹不会追踪，打不中高速移动的飞机，所以对空要单独用这个。
- 射程 5 格，贴近目标才开火，曳光弹是一段短而直的弹道，不会从远处“扔”下去。弹速 130～160。
- 第一枪连发 6～10 发，后面 4 枪紧跟，形成一串密集弹着点。
- 弹头带爆炸范围：机枪 0.5 格、20mm 0.6 格、30mm 0.8 格，边缘伤害 60～70%。没正中也有伤害。
- 对空射程 8 格，另加 `AirRangeBonus=6`，共 14 格，和原来一样。`OmniFire=yes` 保持不变。
- **NAFAF（雅克-9）** 也换成二战武器：ShVAK 20mm 加 UBS 12.7mm，速度 10，血量 300，弹药 3。
- **渡鸦（Ju 87G）**：照原版渡鸦的斯图卡式攻击，弹道 `WW2_StukaP`（`ROT=1`、`Arm=2`、`Cluster=2`），第一枪连发 8 发 37mm，射程 10，只能对地。

**武器命名：** 战斗机沿用自己原来的武器名，直接改数值（如 `MSSL2`、`Maverick9`、`ClusterMissile`，精英版为原名加 `E`）。原名被多个单位共用时才新建：火鸟 `MC205Guns`、NAFAF `Yak9Guns`。对空副武器是原名加 `AA`（精英 `AAE`）。皮肤武器一律是原武器名加 a/b/c/d（如 `MSSL2a`、`MSSL2AAa`、`MSSL2AAEa`），不加 `WW2`。所有新节名都不超过 Ares 限制的 24 个字符。

### 3. 航母
- `CARRIER`、`NIMITZ`、`NODCARRI`：`CanPassiveAquire=yes`，`GuardRange=26`（发射器射程 36 减 10），`Sight=12`。停在海上时，敌人进入 26 格内会自动起飞舰载机攻击。
- 发射器弹道改成 `Invisible3`（`AA=yes AG=yes`），航母可以锁定空中目标，自动派舰载机拦截。
- 黄蜂、蓝鲨、鸭嘴兽加了对空机枪副武器（`WW2_CarrierAirGun`），对地攻击保持不变。

### 4. 坦克：炮和机枪的切换时间
- 炮弹、弹道、弹头全部是原版，虎式也是原来的直线弹道。
- 带机枪的坦克用 Gattling 阶段在炮和机枪之间切换（Ares `Gattling.Cycle`）：阶段 1 是 `Weapon1`（炮），阶段 2 是 `Weapon3`（机枪）。
- 有 26 种坦克的 `Stage1` 比炮的装填时间（`ROF`）长 12 帧。炮会在自己的阶段里开两炮，第二炮的装填拖过机枪阶段，机枪就打不出来。
- 原本正常的坦克（战锤、雄狮、暴风、猎虎等）用的是 `Stage1 = ROF - 24`、`Stage2 = ROF + 48`：每轮只开一炮，装填完成后机枪连续射击 48 帧。现在所有带机枪的坦克都统一成这种写法，精英等级按精英的 `ROF` 算。射速本身不变。

### 5. 飞机皮肤
- NAFAF 的两个皮肤（灰鸥、金色传说）在原作者的雅克-9 模型上重新上色（`tools/voxplane/recolor.py`），武器也换成二战武器，按原加成设计换算。
- 17 个飞机皮肤都换成新的二战模型，按原皮肤的配色主题重新涂装（黑金、金色、蓝黄条纹、青蓝、紫色星点、橙色条带、红橙、灰色/卡其虎纹、深蓝金边、黑红）。预览图在 `previews/skins.png`。
- `artmd.ini`：`FERDA/FERDB/GERNA-D/GERSA/GERZA/GERZB` 原来写着 `Image=基础单位`，直接用基础模型；现在改成用自己的皮肤模型。
- 战斗机皮肤用和基础机一样的二战武器，再按 104 皮肤清单里的加成设计换算：伤害、射速、弹药、速度、血量。皮肤用自己原来的武器名（如 `MSSL2b`），对空副武器为 `MSSL2AAb`。价格没动。
- 黑曜（信天翁）和雷霆（太阳鸟）是轰炸机和攻击机，这次只换模型涂装，数值不动。

## 修复了哪些“摇摇晃晃”的问题

| 问题（codex 版） | 现在 |
|---|---|
| hornet / j35 / su34 的体素间距是 0.607，不是 1.0。体素之间有缝隙，飞机转向时闪烁、镂空，螺旋桨也可能错位 | 所有部件的体素间距都是 1.0，和 NAFAF 一致 |
| 法线和几何形状对不上（平均吻合度 0.81～0.93），有 3～8% 的法线方向反了，转弯时光照忽明忽暗、看起来在抖 | 法线由几何形状平滑计算，吻合度 0.996，没有反向法线 |
| 翼面只有 1 个体素厚，旋转时会出现破洞、闪烁 | 翼面和尾翼至少 2 个体素厚 |
| 螺旋桨只有 2 帧，两帧之间转 45°～60°。游戏飞行时来回切换，大桨叶在两个位置间跳，看起来像重影、左右摇晃 | 螺旋桨改为 6 帧，每帧只转一小格（三叶桨 20°，四叶桨 15°），看起来是连续转动；轴心固定在桨毂上 |
| 机身边界没有居中，下方留了大量空白 | 边界在 x/y 方向居中，z 方向和 NAFAF 一样，大约 30% 在原点以下 |

## 比例

所有飞机按游戏平衡统一大小，不再按真实比例：

- **战斗机（单发）**：翼展统一约 85 体素，和 NAFAF 一样大。
- **双发飞机**：约 103 体素，比战斗机稍大。
- **四发重轰炸机**：约 116 体素。
- **舰载机**（hornet、j35、su34）：保持之前在游戏里的大小，55～88 体素。

模型太大会和旁边的飞机叠在一起，看起来就像重影。要调整的话，改 `tools/voxplane/builder.py` 里的 `SPAN_FIGHTER` / `SPAN_TWIN` / `SPAN_HEAVY`，或者 `aircraft.py` 里的 `CARRIER_S`，然后重新生成。

## 重新生成 / 修改

```
pip install numpy scipy pillow
cd tools/voxplane
python3 gen.py ../../models              # 生成全部
python3 gen.py ../../models hornet j35   # 只生成某几架
python3 check.py ../../models/hornet     # 检查法线、边界、螺旋桨帧
python3 render.py preview.png ../../models/hornet   # 生成预览图
```

- `aircraft.py`：每架飞机的尺寸、机翼、尾翼、发动机、座舱、炮塔、涂装和标志，单位是米。
- `builder.py`：体素化、法线计算、螺旋桨和 HVA 的生成。
- `paint.py`：迷彩、国籍标志、面板线和阵营色。

预览图在 `previews/`，每架飞机有俯视图和 RA2 视角图。
