# 真实二战兰博版：27 架二战飞机模型重制

`models/` 里是按历史资料重新生成的 27 架飞机的 VXL/HVA 文件，直接覆盖到游戏目录即可。`NAFAF`（雅克-9）是参考基准，没有改动。

## 安装

仓库里的 `真实二战兰博版.rar` 已经是更新后的完整版：27 架飞机的 VXL/HVA 已替换，`rulesmd.ini` 也已修改。

1. **先备份**你电脑上现有的“真实二战兰博版”文件夹（原版压缩包可以在仓库历史的第一个提交里找到）。
2. 解压新的 `真实二战兰博版.rar`，覆盖原文件夹。

只想替换模型的话，也可以只把 `models/` 里的 54 个文件复制进游戏目录。

## 对 rulesmd.ini 的修改

所有改动都由 `tools/rules/patch_rules.py` 从原版 `rulesmd.ini` / `artmd.ini` 一次生成，只用尤里的复仇 + Ares 支持的标签（没有 Phobos）：

```
python3 tools/rules/patch_rules.py 原版rulesmd.ini 新rulesmd.ini 原版artmd.ini 新artmd.ini
```

### 1. 飞行姿态（重影、倾斜）
- `PitchSpeed` 过低会让飞机在几个俯仰角之间来回追赶，出现重影。以下单位统一改成 `1.1`：`A10W`、`KPLN`、`JAFSD`、`JAGDS`、`STFIGHTER`、`GERR`、`GERS`、`GERL`、`HORNET`、`J35`、`SU34`，以及下面全部战斗机。
- `RollAngle`：`B2BOMBER`、`STFIGHTER` 改成 `0`（之前停机时会歪）。`STFIGHTER` 的 `PitchAngle` 也改成 `0`。

### 2. 战斗机：二战机炮，对空对地同一把武器

原来能打飞机的战斗机（导弹也好、子弹也好）都只有**一个主武器**，弹道 `AA=yes AG=yes`，而且会跟踪，没有副武器。之前试过两种写法，实测都打不了空：
- 主武器对地扫射、副武器对空：飞机只会用主武器开火，副武器根本不用。
- 扫射弹加上 `AA=yes`：`ROT=1` 的直线弹不会追踪，追不上正在飞的飞机。

所以现在照原来的写法（真实二战里没有使用任何 Phobos 标签）：
- 每架战斗机只有一个主武器，弹道 `WW2_FighterGunP` 照搬原来战斗机子弹 `AircraftCannonP_D1`：`ROT=104` 跟踪，`Proximity=yes` 接近即爆，`AA=yes AG=yes`。子弹会拐弯，对空对地都打得中。副武器已经去掉。
- 跟踪弹不会“扫射”（扫射要求 `ROT` 小于 2），飞机会像原来那样冲向目标开火再拉起。
- 射程 7 格（精英 7.5），比原来的 14 格近，要飞近才开火。另有 `AirRangeBonus=6`，`OmniFire=yes` 保持不变。
- 伤害、连发、射速和弹头不变：连发 6～10 发，弹头带爆炸范围（机枪 0.5 格、20mm 0.6 格、30mm 0.8 格，边缘伤害 60～70%）。
- 不带 `Inaccurate` 的弹药命中时会吸附到目标上，算直接命中。
- **NAFAF（雅克-9）** 也换成二战武器：ShVAK 20mm 加 UBS 12.7mm，速度 10，血量 300，弹药 3。
- **Me 262（风暴战机）**：4 门 MK108 30mm，和其他战斗机不一样。每发 75 伤害，但一次只打 4 发，射程 6，弹速 90。弹道 `WW2_MK108P` 用游戏里的炮弹图像，跟踪性差一些（`ROT=48`）：打轰炸机几发就能打下来，打灵活的战斗机容易打偏。飞机本身速度最快（14），但转弯最差。
- **渡鸦（Ju 87G）**：照原版渡鸦的斯图卡式攻击，弹道 `WW2_StukaP`（`ROT=1`、`Arm=2`、`Cluster=2`），第一枪连发 8 发 37mm，射程 10，只能对地。

**武器命名：** 战斗机沿用自己原来的武器名，直接改数值（如 `MSSL2`、`Maverick9`、`ClusterMissile`，精英版为原名加 `E`）。原名被多个单位共用时才新建：火鸟 `MC205Guns`、NAFAF `Yak9Guns`。皮肤武器一律是原武器名加 a/b/c/d（如 `MSSL2a`、`MSSL2Ea`），不加 `WW2`。所有新节名都不超过 Ares 限制的 24 个字符。

### 3. 航母
- `CARRIER`、`NIMITZ`、`NODCARRI`：`CanPassiveAquire=yes`，`GuardRange=26`（发射器射程 36 减 10），`Sight=12`。停在海上时，敌人进入 26 格内会自动起飞舰载机攻击。
- 航母不对空：发射器和黄蜂、蓝鲨、鸭嘴兽都保持原来的武器，舰载机只做原来那种直线对地攻击。

### 4. 坦克：炮和机枪的切换时间
- 炮弹、弹道、弹头全部是原版，虎式也是原来的直线弹道。
- 带机枪的坦克用 Gattling 阶段在炮和机枪之间切换（Ares `Gattling.Cycle`）：阶段 1 是 `Weapon1`（炮），阶段 2 是 `Weapon3`（机枪）。
- 有 26 种坦克的 `Stage1` 比炮的装填时间（`ROF`）长 12 帧。炮会在自己的阶段里开两炮，第二炮的装填拖过机枪阶段，机枪就打不出来。
- 原本正常的坦克（战锤、雄狮、暴风、猎虎等）用的是 `Stage1 = ROF - 24`、`Stage2 = ROF + 48`：每轮只开一炮，装填完成后机枪连续射击 48 帧。现在所有带机枪的坦克都统一成这种写法，精英等级按精英的 `ROF` 算。射速本身不变。

### 5. 步兵
- 迫击炮兵（`RGI`）架炮后的武器（`Thapao` / 精英 `ThapaoE`）伤害各加 2：65→67，75→77。只有迫击炮兵用这两个武器。

- 17 个飞机皮肤都换成新的二战模型，按原皮肤的配色主题重新涂装（黑金、金色、蓝黄条纹、青蓝、紫色星点、橙色条带、红橙、灰色/卡其虎纹、深蓝金边、黑红）。预览图在 `previews/skins.png`。

### 8. 海岸炮（`GAGUN`）重做

- 底座（`tools/shp/coastbattery.py`）：八角形混凝土棱堡，外面一圈卡其色沙袋，中间一圈大块红色阵营色带，钢门上方一块红色阵营色方块，顶上是带光泽的淡紫灰钢制炮座圈。画法照红警2/尤里的复仇的建筑：大块简单形体、饱和颜色、明暗对比强、钢件有光泽、阵营色面积大。色感和热卫激光塔、警戒哨塔一致，不走其他模组那种细碎写实的风格。高度和热卫激光塔差不多。普通地图 `gggun*`、雪地 `gagun*`（地面和沙袋上有雪），含 3 张状态图（完好、受损、重损）和建造动画。
- 炮塔（`tools/voxplane/coastturret.py`）：体素模型，由游戏引擎自己绘制（`rulesmd` 里 `TurretAnimIsVoxel=true`，和原版海上巨炮、巨炮一样），光照和坦克、船只一致。`gaguntur.vxl` 是双联装甲炮塔（两侧红色阵营色板、测距仪、舱盖、炮门），`gagunbarl.vxl` 是两根长炮管（带炮衣和炮口环），立在棱堡顶上的炮座圈上。
- 文件都在 `models/buildings/`。`artmd` 的 `Height` 保持 2。
- 武器 `190mm`（只有海岸炮用）：双管就双发，`Burst=2`，每发 180（原来一发 300）。弹道换成重型坦克主炮的曳光弹 `HeavyShellP_D2`（和潘兴、毁灭者、斐迪南一样的直射弹），弹速 110；原来的抛射弹 `CoastCannonP` 不再使用。
- 开火位置：`PrimaryFireFLH=282,22,144`，`PrimaryFireDualOffset=yes`（两发分别从左右炮口射出）。体素单位换算成像素和 lepton 是按原版坦克模型估算的（约 0.66 像素、4.6 lepton 一个单位）；如果游戏里炮塔高低或炮口火光有偏差，改 `coastturret.py` 的 `FLOOR` 和这个 FLH。
