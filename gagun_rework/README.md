## 2. 违和原因分析（相对于截图中的周边建筑）

- 周边建筑：主体为深灰/黑灰金属，亮部只落在顶面和棱边；土黄/橙色（阵营色）以嵌板、条带的形式有节奏地出现；
  底座有“深色加强肋 + 阵营色嵌板”的层次；阴影统一投向右下（光源在左上方）。
- 原海岸炮的问题：扁平圆盘底座太简单，缺少承重、固定的感觉；炮塔体量小，炮管像直接插进箱体；
  炮管朝北时看起来像一根细长天线；炮塔与底座之间缺少旋转座圈和接触阴影。

## 3. 重制设计

- **底座**：八角形混凝土基台 → 倾斜装甲裙座（8 根加强肋，肋脚黄铜螺栓）→ 深色缝隙 → 黄铜旋转座圈；
  肋与肋之间的下部是阵营色嵌板（随玩家颜色变化，与周边建筑一致）；正面有黄铜框弹药舱门。
- **炮塔**：二战岸防/舰炮式装甲炮室——倾斜正面装甲、倾斜侧装甲、带倒角的后部配重舱、侧装甲接缝、
  后部黄铜框装填门和通风百叶、观察窗。
- **火控**：删除细长天线，改为炮室后顶横置的**低矮光学测距仪**（两端装甲护罩 + 镜片），
  以及一个低矮的指挥塔潜望镜。
- **炮管**：炮耳座（防盾）→ 驻退套筒 → 黄铜锁环 → 长身管（锥度、中段加强箍、炮口加强环、炮膛暗孔），
  略带仰角；身管按受光方向有亮面/暗面/高光。
- **光影**：与原素材相同的光向；炮塔底部与座圈之间有接触暗线；受光棱边提亮 1 级，背光轮廓压暗 2 级。
- **颜色**：只使用调色板 16–203 号（其中 16–31 为阵营色），不使用 0–15 特殊色和 204–254 未使用区。
- **雪地版（GA*）**：参照 Mod 内电厂雪地版 `GARPOW` 的画法——所有接近水平的朝上表面（炮塔顶、测距仪、炮管上沿、加强肋顶、基台）按法线自动积雪，雪线带噪点不规则，雪的暗部为淡蓝灰（调色板 32–36、80–88），带少量闪点；雪线下方的竖直面有零星 1–2 像素冰挂；斜裙座和阵营色嵌板保持露出。炮塔 32 个方向单独渲染带雪版本；建造动画中施工截面不积雪。
- **受损帧**：局部焦痕、打断的加强肋、裙座和基台上的弹坑缺口（结构仍可辨认）。
- **建造动画**：底座从地面逐层升起（7 帧）→ 炮室逐层组装（5 帧）→ 完成帧与正常状态完全一致。

32 个方向由同一个 3D 模型按游戏的正交投影（30° 俯角）渲染，结构、尺寸、炮管长度在所有方向保持一致。

## 5. 直接替换（GG 通用/温带 + GA 雪地）

仓库根目录的 `真实二战兰博版_海岸炮替换/真实二战兰博版/` 里已经是改好名的最终文件：

```
gggun.shp  ggguntur.shp  gggunmk.shp     通用/温带（GG）
gagun.shp  gaguntur.shp  gagunmk.shp     雪地（GA）
```

把这个 `真实二战兰博版` 文件夹的内容复制到 Mod/游戏目录覆盖同名文件即可（真实二战原版如果用的是同名文件，同样适用）。
原来的 6 个文件备份在 `gagun_rework/backup_original/`，要还原就把它们复制回去。
（本环境无法写入 RAR 格式，所以没有直接修改 `真实二战兰博版.rar`。）

**阵营色**：阵营色部分（裙座下部嵌板、炮塔后部两侧条带）使用调色板 16–31 号红色阶，与原素材相同，
进游戏会自动变成各玩家的颜色；预览图里的橙色只是按截图玩家颜色模拟的，`preview/remap_and_snow.png` 里有红/橙/蓝/绿/黄的对比，以及雪地版与 GARPOW 的对照。

**雪地版**：GA 底座、炮塔（32 方向）和建造动画都带积雪，画法参照 Mod 内电厂雪地版 GARPOW。注意：这个 Mod 里多数 GA/GG 建筑文件内容完全相同，真正画了雪的只有电厂（和原版海岸炮的少量像素）。

## 6. 游戏内测试方法

1. 先备份游戏目录中现有的 `gggun.shp / ggguntur.shp / gggunmk.shp / gagun.shp / gaguntur.shp / gagunmk.shp`
   （仓库里的 `backup_original/` 也有一份）。
2. 把 `shp/` 中的文件复制到游戏目录，并按上表去掉 `_rework_v01` 改名。
3. 进游戏检查：
   - [ ] 第一眼是否还会特别白、特别显眼
   - [ ] 与左侧两座炮台是否属于同一美术体系；是否比周边过于精细或过于简单
   - [ ] 阴影方向、炮塔与底座是否对位（`TurretAnimZAdjust=-60` 等参数未改）
   - [ ] 32 个方向旋转是否顺畅、开火时炮口火光位置是否合适（`PrimaryFireFLH=200,0,120` 未改）
   - [ ] 受损状态、建造动画、雪地地图
   - [ ] 有无白边/黑边/调色板错误；换不同玩家颜色时阵营色嵌板是否正常

## 7. 已知限制 / 需要你确认

- **未进游戏验证**：旋转、开火、受损、建造只在渲染预览中检查过静态帧，不能声称游戏内完全正常。
- **调色板**：压缩包里没有 `unittem.pal`/`unitsno.pal`。这里使用的是 Mod 自带 193 个 VXL 文件头中内嵌的同一份单位调色板，

  雪地调色板没有拿到，雪地版按相同索引制作。若你能提供实际的 `.pal`，可以重新校色。
